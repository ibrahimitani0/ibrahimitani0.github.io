About Me

A Quick Overview

Software Engineer & Systems Builder

I am a software engineer specializing in building robust back-end services, scalable architectures, and data-driven web applications. My work focuses on writing clean, maintainable code and solving complex technical challenges across the full stack.


I hold a degree in Computer Science and bring over four years of professional engineering experience building enterprise applications. My background spans full-stack development, database query optimization, and migrating legacy financial and operational systems into modern, high-performance architectures.


On the backend, I design and build secure RESTful APIs and enterprise services using Java, Spring Boot, and robust SQL databases (Oracle & MSSQL). On the frontend, I build dynamic, responsive user interfaces using Angular and TypeScript to deliver seamless user experiences.


Engineering Philosophy

I believe in writing code that is scalable, testable, and maintainable. Whether I am refactoring heavy enterprise database queries, structuring API endpoints, or designing clean UI components, I focus on system performance, efficiency, and writing code that other developers can easily read and scale.


Technical Stack

My core tech stack includes Java, Spring Boot, Angular, JavaScript/TypeScript, SQL, REST APIs, Git, AWS, and Power BI. I am comfortable working in Agile environments, managing version control pipelines, and integrating services from database to UI.


Beyond the Terminal

Outside of coding, I enjoy reading, playing guitar, gaming (including tinkering with custom vehicle builds and tuning specs in Forza Horizon), and building personal software projects.


Connect with me on LinkedIn or drop me an email. I am always open to discussing new engineering projects, backend challenges, or software architecture.
